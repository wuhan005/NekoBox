# NekoBox 账号注销协议

本《NekoBox 账号注销协议》（以下简称“**本协议**”）是 NekoBox 账号持有人（以下简称“**您**”）与 NekoBox 个人开发者及运营者（E99p1ant，以下简称“**我们**”）之间，就解除双方此前达成的[《NekoBox 服务条款》](./terms)、停用并注销您的 NekoBox 账号及相关事宜所作的说明与约定。

在 NekoBox 网站界面中，账号注销功能以“**停用账号**”形式呈现。**在您点击“我确认停用账号”之前，请务必认真阅读并充分理解本协议的全部内容。**

# 【特别提示】

1. **停用（注销）账号为立即生效且无法撤销的操作。** 一旦您在确认页面点击“我确认停用账号”，操作将即时完成，无静默期，且无法自行恢复。

2. **请务必在停用前自行备份您的数据。** 您可以在登录状态下前往“设置 → 账号设置”，点击“导出我的数据”，将您的账号基本信息以及收到的全部提问和回答导出为 Excel 文件（`.xlsx`）保存至本地。

3. **停用后您将无法再访问原账号及提问箱。** 您将无法使用该账号再次登录，也无法自行找回该账号下的配置信息、提问与回答内容。

4. **停用账号并不免除停用前的相关责任。** 您仍应对账号停用前在该账号下实施的行为以及发布的内容承担相应的法律责任。

# 一、账号停用（注销）的操作方式与前提

## 1.1 操作路径 

您可以通过以下自助流程完成账号停用（注销）：

1. 登录您需要停用的 NekoBox 账号；
2. 点击顶部导航栏进入“设置”，切换至“账号设置”标签页；
3. 如需留存记录，请先点击“导出我的数据”完成本地备份；
4. 点击“停用我的账号”进入停用确认页面；
5. 仔细阅读页面提示后，点击“我确认停用账号”，系统将立即执行停用操作并退出登录。

## 1.2 停用前提

在执行账号停用操作前，请您确认满足以下前提：

- （1）您仅可操作停用您本人合法持有的账号；
- （2）您已自行导出并妥善备份了希望保留的个人资料与问答数据，已妥善处理账号下的相关服务状态，并明确放弃保留或恢复该等数据及相关状态；
- （3）您停用账号并非为了逃避正在进行的违法违规调查、侵权投诉或争议纠纷处理。

# 二、账号停用（注销）后的后果

**您知悉并同意，点击“我确认停用账号”后将立即产生以下后果：**

- （1）**无法再登录使用**：您当前的登录会话立即失效，您将无法再使用该账号登录 NekoBox，也无法再使用需登录方可使用的一切功能（如管理提问、修改设置或编辑像素画板）；
- （2）**提问箱与问答无法访问**：您的专属提问箱页面（`/_/<个性域名>`）以及该提问箱下的所有公开和私密提问都将无法再被访问，其他人也无法再向您发送新的提问；
- （3）**发出的提问记录不再可查**：您在登录状态下曾向其他用户发出的提问，在对方提问箱中仍以匿名形式独立存在（不会展示您的身份），但停用后您将无法再通过“我的提问”查看或管理这些记录；
- （4）**数据与状态无法自行恢复**：您无法再通过网站自助方式恢复该账号，也无法找回该账号下的个人信息、提问箱配置、收到的提问、回答记录及其他与该账号关联的服务状态；
- （5）**停止相关通知与服务**：我们将不再向该账号提供服务，也不再向该账号发送新提问邮件通知。

关于已停用账号历史数据的留存与清理，我们将依据[《NekoBox 隐私政策》](./privacy)及相关法律法规的要求执行。**如您在停用后仍有进一步彻底删除历史留存数据的需求，请通过页面底部的[吐槽反馈](https://support.qq.com/products/293656)或 [GitHub 仓库](https://github.com/wuhan005/NekoBox)联系运营者，我们在核实账号归属后将尽快协助处理。**
