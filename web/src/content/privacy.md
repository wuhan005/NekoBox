# NekoBox 隐私政策

NekoBox（以下简称“**本网站**”或“**本服务**”）是由个人开发者（E99p1ant，以下简称“**我们**”或“**运营者**”）独立开发并运营的匿名问答箱网站，不涉及任何公司或企业主体。我们尊重并重视您的个人隐私，始终秉持**最小必要**的原则收集和处理信息，**不会出售您的个人信息，也不会接入商业广告或营销追踪服务**。

在您访问、注册或使用本网站之前，请仔细阅读并理解本隐私政策。**其中涉及重要权利义务及跨境存储说明的内容已以加粗形式提示，请您重点关注。** 如果您不同意本隐私政策的内容，请停止使用本网站；当您继续访问、注册或使用本网站时，即视为您理解并同意我们按照本政策处理您的相关信息。

本隐私政策将帮助您了解：

- 三、信息存储地点、基础设施与期限
- 四、第三方服务、信息共享与公开披露

# 一、我们如何收集和使用信息

## 1.1 账号注册、登录与找回密码

本网站支持浏览公开问答与匿名提问，无需注册即可使用基础功能。当您选择注册或登录 NekoBox 账号时，我们会收集以下信息：

- **注册信息**：您主动填写的电子邮箱地址、个性域名、昵称以及登录密码。您的登录密码会在服务端经加盐哈希算法加密后存储，**我们不保存您的明文密码**。
- **登录与找回密码**：登录时我们核验您提供的电子邮箱与密码；当您使用“忘记密码”功能时，我们会使用您填写的电子邮箱发送一次性密码重置链接（有效期 24 小时）。
- **明确不收集的信息**：本网站无需实名认证，**不收集您的真实姓名、身份证件号码或手机号码**，也不提供第三方社交账号授权登录。

## 1.2 提问箱配置与个人偏好

登录账号后，您可以在“设置”页面或顶部导航栏配置以下信息，这些信息将用于展示您的提问箱页面及实现个性化偏好：

- **提问箱公开资料**：昵称、个性域名、提问箱介绍、上传的自定义头像和背景图；
- **功能设置**：新提问邮件通知开关、防骚扰设置（是否仅允许注册用户提问、自定义屏蔽词列表）以及页面外观主题偏好（浅色 / 深色 / 跟随系统）。

## 1.3 提问、回答与图片上传

- **提问与回答内容**：当您发送提问或回复提问时，我们会存储您提交的文字内容、附带图片、公开/私密状态及系统生成的随机访问凭证（用于生成“提问私密链接”）。
- **上传图片记录**：当您上传头像、背景图或问答配图时，我们会记录图片的原始文件名、文件大小、MD5 校验值、存储路径，以及（在登录状态下的）上传者内部账号 ID。
- **回复通知邮箱（可选）**：当您在提问页面主动勾选“我想接收回复通知”并填写电子邮箱时，我们仅使用该邮箱在提问箱主人**首次回复**该问题时向您发送一封通知邮件。
- **登录状态下的提问关联**：如果您在已登录状态下向他人提问，系统会记录您的内部账号 ID，**仅用于向您本人在“提问 → 我的提问”列表中展示您的提问记录，不会向提问箱主人或其他任何人公开展示您的账号身份**。
- **防滥用 IP 记录**：在提交提问时，为防范恶意刷屏、骚扰行为及排查安全事件，系统会记录提交该提问时的请求来源 IP 地址。该 IP 地址不对外公开展示。
- **像素画板**：未登录用户可浏览画板；已登录用户参与绘制时，将使用当前登录会话凭证验证您的编辑权限。

## 1.4 邮件通知

我们仅会在以下与您的账号或操作直接相关的场景下向您主动提供的电子邮箱发送事务性邮件：

- 您主动发起密码找回请求时；
- 您在提问箱设置中开启了“邮件”通知且收到新提问时；
- 您在提问时主动勾选并填写了接收回复通知的邮箱，且该提问首次获得回复时。

**我们不会向您发送商业推广、广告营销或调研类邮件。** 您可以随时在“设置 → 提问箱设置”中关闭新提问邮件通知。

## 1.5 内容安全检测（如开启）

为防止违法违规内容传播，在站点开启文本内容安全检测功能的情况下，您提交的提问文本和回答文本可能会被发送至第三方内容安全接口进行自动化审核。服务端可能会缓存审核结果及对应的文本哈希（缓存期限最长约 1 个月）以避免重复检测。

## 1.6 服务运行日志与链路追踪

- 为保障网站稳定运行、防御网络攻击及排查程序故障，我们的服务器和网络代理会处理必要的技术请求信息，例如请求来源 IP 地址、请求路径、HTTP 方法与状态码、响应耗时、错误堆栈，以及在已登录状态下用于定位问题的内部用户 ID。
- **链路追踪说明**：本网站使用 **Uptrace**（基于 OpenTelemetry）进行服务端链路追踪与错误排查。**除此之外，本网站没有接入任何其他第三方统计分析、用户画像、广告归因或行为追踪服务。**

# 二、本地存储、Cookie 与同类技术的使用

2.1 **浏览器本地存储（localStorage）**：本网站前端在您的浏览器 `localStorage` 中保存您的登录会话凭证（Session ID 及基本公开资料，用于维持登录状态并在请求接口时通过 `Authorization` 请求头鉴权）以及外观主题偏好（浅色 / 深色 / 跟随系统，用于在页面加载时避免主题闪烁）。您点击“退出登录”或清理浏览器站点数据即可清除上述本地信息。

2.2 **安全与验证类 Cookie**：本网站接入的网络防护服务（Cloudflare）及人机验证组件（按站点配置启用，例如滑动验证码或 reCAPTCHA / Turnstile）可能会在您的浏览器中设置必要的安全类 Cookie，仅用于区分正常访客与自动化恶意流量，保障站点安全。

2.3 您可以通过浏览器设置管理或清除本地存储与 Cookie，但禁用后可能会导致无法保持登录状态或无法通过人机验证。**我们不会使用 Cookie 或同类技术进行跨站行为追踪或广告定向投放。**

# 三、信息存储地点、基础设施与期限

## 3.1 存储地点与跨境数据处理

**本网站的核心服务端与数据库部署在腾讯云日本东京区域，前端页面托管、CDN 加速及网络防护由 Cloudflare 全球边缘网络提供，服务端链路追踪数据上报至 Uptrace。**

**这意味着，当您访问或使用本网站时，您提交的数据与技术请求日志将会在中国大陆以外的服务器及网络节点上进行传输、处理和存储。** 您继续使用本网站即表示您知悉并同意上述数据存储与跨境传输安排。我们会采取合理的技术手段保护数据传输与存储过程的安全。

## 3.2 存储期限

- **账号与问答数据**：在您持续使用账号且未删除相关内容期间，我们将为您保留账号资料与问答记录；当您删除单条提问后，该提问将不再展示或提供访问；当您停用（注销）账号后，您的账号将无法登录，提问箱页面及提问将无法访问。
- **临时会话与凭证**：服务端登录会话数据在 Redis 中保留最长 30 天（在退出登录、修改密码或重置密码时会提前失效）；密码找回重置码有效期为 24 小时，过期自动失效。
- **链路追踪与安全日志**：仅在排查故障、保障安全或法律法规要求的必要期限内留存，到期后自动清理或覆盖。

# 四、第三方服务、信息共享与公开披露

## 4.1 实际涉及的第三方技术服务

我们不会出于商业目的向第三方出售、出租或共享您的个人信息。为实现本网站的正常部署与核心功能，以下基础设施与功能性服务方可能会在必要范围内处理相应技术数据：

- **腾讯云（日本东京区域）**：提供后端应用服务器与数据库托管服务；
- **Cloudflare**：提供前端托管、CDN 加速、边缘转发及 DDoS / 恶意流量防护服务；
- **Uptrace**：提供服务端 OpenTelemetry 链路追踪与错误监控服务（**除此之外无其他追踪服务**）；
- **对象存储与 CDN 服务**：用于存储和分发用户上传的头像、背景图及提问/回答中的图片；
- **SMTP 邮件服务**：用于发送密码找回、新提问提醒及回复通知等事务性邮件；
- **人机验证服务与内容安全检测服务（按站点实际启用配置）**：用于在注册、登录、找回密码和提问时防止机器人滥用，以及对提问/回答文本进行合规检测。

如后续因产品功能迭代需要接入新的第三方服务，我们将在相关功能提供前更新本政策或在对应页面予以说明。

## 4.2 公开披露与法定例外

除您主动设为公开的提问箱资料、公开问答内容及在公共画板上的创作外，原则上我们不会公开披露您的个人信息（例如您的电子邮箱、密码哈希、私密提问、登录提问者关联信息及来源 IP）。但在以下情形下，我们可能会依据法律法规或有权机关的要求提供必要信息：

- （1）获得您的明确同意；
- （2）为履行法律法规规定的义务，或响应司法机关、公安机关等有权国家机关的依法调取要求；
- （3）为维护公共安全、您或他人的生命财产等重大合法权益所必需；
- （4）为处理严重违法违规行为或保障本网站安全稳定运行所必需。

## 4.3 站点停止运营或维护变更

由于本网站为个人开发并运营的项目，如未来因故计划停止运营或变更维护者，我们会尽可能提前在网站首页“开发日记”或显著位置发布公告，为您预留合理时间通过“数据导出”功能备份数据，并在停止运营后停止收集信息并对留存数据进行删除或匿名化处理。

# 五、我们如何保护您的信息安全

5.1 我们采取符合行业常规实践的技术措施保护您的数据安全，包括全站使用 HTTPS 加密传输、对用户密码进行加盐哈希存储、修改或重置密码后自动使所有旧登录会话失效、严格限制数据库与服务器访问权限等。

5.2 **请您理解，本网站由个人开发者独立维护，且互联网环境并非绝对安全。尽管我们会尽合理努力保障信息安全，但无法承诺绝对免受任何恶意攻击或意外故障。我们强烈建议您使用独立的高强度密码，不要在其他网站重复使用相同密码，并定期使用“数据导出”功能自行备份您的重要问答记录。**

5.3 如不幸发生可能影响您个人信息安全的事件，我们将在知悉后尽快排查止损，并通过网站公告或邮件等方式及时告知您相关情况与建议采取的防范措施。

5.4 **本隐私政策仅适用于 NekoBox 网站本身。** 页面中指向的外部网站或服务（例如页脚的[吐槽反馈](https://support.qq.com/products/293656)、[GitHub](https://github.com/wuhan005/NekoBox) 或赞赏页面涉及的第三方支付平台）均由对应第三方独立运营，适用其各自的隐私政策，我们对第三方网站的隐私实践不承担责任。

# 六、如何管理您的个人信息

您可以通过本网站提供的自助功能直接管理您的个人信息：

- **查阅与修改基本资料**：登录后进入“设置 → 个人信息”，可查看您的注册电子邮箱（不可自主修改），修改您的昵称或登录密码；进入“设置 → 提问箱设置”和“设置 → 防骚扰设置”，可随时更新提问箱介绍、头像、背景图、邮件通知开关及防骚扰规则。
- **管理提问与回答**：登录后进入“提问”页面，可查看“我收到的问题”与“我的提问”。对于您收到的问题，您可以在问题详情页随时修改回答、切换“设为公开 / 设为私密”或点击“删除提问”将其删除。
- **导出数据副本**：登录后进入“设置 → 账号设置”，点击“导出我的数据”，即可直接下载 Excel 文件（`.xlsx`），内含您的账号基本信息（电子邮箱、昵称、个性域名、介绍、头像与背景图链接、注册时间）以及您收到的全部提问与回答。
- **停用（注销）账号**：登录后进入“设置 → 账号设置”，点击“停用我的账号”并按提示确认，即可立即停用账号。具体规则请参见[《NekoBox 账号注销协议》](./deactivate-account-terms)。
- **进一步删除或咨询**：如您有超出上述自助功能范围的数据删除请求（例如希望彻底清除已停用账号的历史留存数据或排查隐私问题），可通过页脚的反馈渠道联系我们，我们在核实您的账号归属后将在合理期限内协助处理。

# 七、未成年人使用提示

本网站是一个面向普通互联网用户的公开匿名问答平台，并无专门针对未成年人设计的服务。**如果您是未满 18 周岁的未成年人，请在您的父母或其他监护人的同意和指导下使用本网站，切勿在提问或回答中泄露真实姓名、家庭住址、联系方式等个人敏感信息。** 如果监护人发现未成年人在未经同意的情况下向本网站提供了个人信息，请及时联系我们，我们核实后将尽快予以删除。
