# 一、服务内容说明

1.1 NekoBox 仅通过网页端提供服务，不提供官方独立的移动客户端（App）。本网站的核心功能包括：

- 为注册用户提供专属的匿名提问箱页面（网址形式为 `/_/<个性域名>`）及分享二维码；
- 允许访客在未登录（匿名）或已登录状态下向提问箱发送文字及图片提问，并支持勾选“回复后不公开提问”或填写电子邮箱以接收首次回复通知；
- 允许提问箱主人查看、回复（支持文字及图片）、切换公开/私密状态及删除收到的提问；
- 提供基础防骚扰设置（如“仅允许注册用户向我提问”及自定义屏蔽词）、新提问邮件通知、个人数据导出（Excel 格式）以及账号停用功能；
- 提供公共像素画板等附加互动功能（未登录用户可浏览，登录用户可参与绘制）。

1.2 本网站当前向用户提供基础的免费问答箱功能。如后续本网站提供需遵守单独规则或额外说明的功能或服务，具体内容与适用条件将以对应页面展示或补充协议为准，并由您自主选择是否使用。

1.3 网站“我要打钱”页面仅用于接受用户对个人开发者分担服务器开销的自愿赞赏，属于无偿支持行为，不对应任何特定功能权限或服务承诺。

# 二、账号管理

## 2.1 账号注册与登录

2.1.1 浏览已公开的问答内容或在默认设置下向他人发起匿名提问无需注册账号。若您希望拥有自己的提问箱、管理问答、在“我的提问”中保留提问记录、使用仅限注册用户参与的功能（如向开启防骚扰限制的提问箱提问或编辑像素画板），您需要注册一个 NekoBox 账号。

2.1.2 您可以通过顶部导航栏的“注册”页面，填写电子邮箱地址、个性域名、昵称并设置密码，完成人机验证后创建账号。**本网站无需实名认证，不收集您的手机号码，也不提供第三方社交账号绑定登录。**

2.1.3 **您设置的个性域名、昵称、头像、背景图及提问箱介绍等公开信息，不得违反国家法律法规及本条款规定，不得包含违法、低俗、骚扰或侵权内容，不得未经授权冒用他人名义或身份。如发现违规，我们有权在不事先通知的情况下采取删除相关内容、限制功能或停用账号等措施。**

## 2.2 账号安全与密码找回

2.2.1 您应妥善保管自己的登录邮箱与密码，并对该账号下发生的所有操作和发布的内容负责。您在公共或他人设备上使用完毕后，应及时在“设置 → 个人信息”页面点击“退出登录”。

2.2.2 **您的账号仅限本人使用，请勿将账号出借、转让、出售或与他人共享。因您自身保管不当（包括但不限于泄露密码、使用弱密码、在不可信设备上保持登录等）导致的账号被盗或数据损失，由您自行承担责任。**

2.2.3 如您遗忘密码，可通过登录页的“忘记密码”功能输入注册邮箱并完成人机验证，系统将向该邮箱发送密码重置邮件（重置链接 24 小时内有效）。重置密码或修改密码后，该账号在其他设备上的已有登录会话将自动失效。**请您在注册时尽量填写本人可控且真实有效的电子邮箱；若您填写了无法接收邮件的虚构或无效邮箱，您将无法通过邮件找回密码或接收通知，由此产生的后果需由您自行承担。**

**在发生以下任一情形时，我们有权视情节轻重，采取删除内容、限制部分或全部功能、停用或封禁账号等措施：**

- （1）违反相关法律法规或监管部门的要求；
- （2）违反本条款规定的使用规范或内容规范；
- （3）遭到他人合理投诉或举报，经核实存在侵权、骚扰、诽谤等违规行为；
- （4）存在恶意批量注册、自动化刷屏、攻击站点或其他危及网站安全稳定运行的异常行为；
- （5）司法机关、公安机关或其他有权国家机关依法要求配合处理的情形。

## 2.4 账号停用（注销）

2.4.1 如您决定不再使用您的账号，可随时登录本网站，进入“设置 → 账号设置”，自行导出个人数据后点击“停用我的账号”，并在确认页面完成操作。具体流程及后果请阅读[《NekoBox 账号注销协议》](./deactivate-account-terms)。

2.4.2 **账号停用操作立即生效且无法撤销，停用后您将无法再登录该账号或找回原账号数据。账号停用不免除您在停用前因使用本网站产生的任何法律或违规责任。**
